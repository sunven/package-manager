# P1：跨管理器搜索、环境诊断与历史对比

状态：已实现。前端 291 项、Rust 259 项测试通过（9 项需专用环境的测试未运行），构建通过；浏览器验证、独立界面审查和设计文档核对见 [VERIFICATION.md](VERIFICATION.md)。

用户已确认并要求实现：顶部按钮／⌘K 搜索已启用管理器的当前观察，应用 PATH 文件系统诊断，完整扫描结束后自动保存快照，以及管理器缓存清理／全局包卸载的持久维护记录。

搜索通过稳定身份定位，保留不同管理器和安装版本。诊断不执行候选程序或 Shell 初始化脚本。历史按管理器保留最近 20 份快照，全局保留 200 条维护记录；历史不充当维护授权。失败、不完整和来源变化不能产生确定的安装／卸载结论，目录占用变化不等于实际释放空间。执行与重新核对的结果分别记录，历史写入失败不改变操作事实。CLI 兼容性、其他来源维护历史、自动修复和升级不在本轮。

验收覆盖搜索定位与键盘、PATH 优先级与链接、快照差异与完整性、历史重启／限额／损坏／写入失败、维护与核对结果分离。运行前后端回归、构建，以及桌面明暗主题界面检查。
