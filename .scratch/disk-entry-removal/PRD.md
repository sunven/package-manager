# 磁盘条目移除

Status: done

## 目标与已确认要求

在磁盘扫描结果中增加移除操作。用户于 2026-11-20 调用 `grill-with-docs`，明确要求“删除就是放到废纸篓”；操作语义已确定为移入系统废纸篓。

领域术语使用 [CONTEXT.md](../../CONTEXT.md) 中的「磁盘条目移除」。需求访谈于 2026-11-20 完成，用户已对三轮 Q1–Q17 全部回复「按推荐」，随后要求「实现」。功能已实现，验证结果与平台边界见 [VERIFICATION.md](VERIFICATION.md)。

## 已确认决策

2026-11-20，第一轮 Q1–Q4，用户回复「按推荐」：

- **Q1 对象范围**：普通文件和整个目录都允许移除，不限于缓存、依赖目录或其他派生数据。选中目录时连同内容整体移入废纸篓；扫描起点本身不提供移除入口。
- **Q2 操作粒度**：同时支持单项移除和勾选多项批量移除，按钮统一使用「移到废纸篓」。
- **Q3 视图入口**：列表与矩形树图都提供移除入口，保留现有点击目录进入的导航行为。
- **Q4 扫描时机**：扫描遍历结束或主动停止后才允许移除；扫描中禁用移除。达到条目上限后的部分结果也可进入移除流程，具体条目资格见 Q7、Q8。

## 已核实的现状与约束

- [原磁盘扫描需求](../disk-scan/PRD.md) 把删除排除于首版范围，本需求是后续扩展。磁盘扫描本身仍是一轮只读观察，不自动构成移除授权。
- [矩形树图需求](../disk-scan-treemap/PRD.md) 已实现列表和矩形树图共享本轮记录及当前目录；目录点击进入，文件方块点击后显示详情。当前没有用于批量移除的选择状态。
- 扫描结果包含文件、目录、符号链接、其他磁盘挂载、特殊或未知条目。内部符号链接、其他磁盘和特殊条目只展示排除状态，不测量目标内容。
- 目录占用沿用 [ADR-0037](../../docs/adr/0037-disk-scan-footprints-deduplicate-per-directory.md)：每个目录独立去重硬链接，子项之和可能超过父目录。因此不能把移除条目的占用简单从祖先占用中扣除并声称是新的测量结果。
- 应用已有移入废纸篓的能力，磁盘扫描尚未接入。既有会话记录和 Maven 构件移除的资格规则各自独立，不自动套用到磁盘条目。
- 扫描中的 `mount` 类型只按设备号与起点不同来识别，没有读取挂载表；同设备挂载不会因此被识别。父目录包含被排除的挂载条目时仍可显示扫描完整，停止或达到上限还可能尚未发现更深层挂载。执行资格不能只依赖扫描类型或完整度。
- 当前扫描节点没有保存执行前复核所需的对象身份，祖先路径也没有完整的身份复核；Q10 需要补充本轮观察证据与执行时复核，不能把重建出来的路径直接交给移除函数。
- 现有系统废纸篓函数委托 Finder 并等待调用结果；没有单项超时、取消或移入后复核。仓库证据不足以证明目录内链接、挂载与外接盘的全部实际行为；这些场景需要在实现时以隔离临时目录定向验证，不能当作已验证的平台保证。

## 第二轮已确认决策

2026-11-20，第二轮 Q5–Q13，用户回复「按推荐」：

- **Q5 选择范围**：批量选择限制为当前目录直接子项；加载后续行保留勾选，「全选」仅选择当前分组已经展示的可移除条目，并明确标为「全选已显示」。进入其他目录、切换分组或开始新扫描清空选择；同目录切换列表与树图保留选择。
- **Q6 具体入口**：列表行提供单项操作和复选框；树图文件详情提供单项操作，文件与目录方块右键均提供操作菜单；进入目录后，非扫描起点的目录还可从路径栏旁的菜单整体移除。树图批量操作通过切到列表勾选，聚合块继续只用于打开分组列表。
- **Q7 条目资格与保护边界**：首版仅支持普通文件和目录，符号链接、挂载点、特殊与未知条目禁用移除；扫描起点、当前用户主目录及其祖先目录禁止移除。没有权限或系统拒绝时报告失败，不申请提权。
- **Q8 不完整目录**：扫描结束后，即使目录未完整读完，也允许用户明确选择将整个目录移入废纸篓；确认中指出占用不完整，操作包含尚未扫描到的内容。此操作选择整个目录，不根据扫描清单逐个移除其后代。
- **Q9 确认**：单项和批量都先显示一次确认框，列出目标完整路径与数量，指出目录会整体移入、废纸篓清空前不承诺释放空间；取消不执行。
- **Q10 执行时变化**：执行前复核目标与所在路径仍对应本轮观察到的对象；消失、被同名新对象替换或路径改成符号链接时跳过并说明原因。仍为同一对象时，内容或大小变化不取消用户对该对象的明确选择，目录新增内容随目录整体移入。
- **Q11 批次行为**：逐项执行并报告已移入、跳过与失败；单项失败继续其余项。显示进度并提供停止后续项的操作，当前正在移入的项完成后再停止；系统废纸篓操作失败只报告，不退化为永久删除。
- **Q12 结果刷新**：操作结束后保留逐项结果，将本轮观察标记为已变化，并自动从原扫描起点重扫以更新目录大小与图表；尽量恢复原浏览目录，已被移除则回到仍存在的祖先目录。刷新失败与移除结果分开显示。
- **Q13 恢复与历史**：恢复交给系统废纸篓，首版不增加应用内撤销或清空废纸篓；接入现有维护历史，记录确认路径与逐项目标结果。

Q8、Q10 关于选择整个对象的取舍记录在 [ADR-0038](../../docs/adr/0038-disk-entry-removal-selects-whole-objects.md)。

## 第三轮已确认决策与最终范围

2026-11-20，第三轮 Q14–Q17 及最终范围，用户回复「按推荐」：

- **Q14 目录内部的排除项**：目录中的符号链接和特殊条目随整个目录一起移入，不跟随链接移动其目标；Q7 禁止的是把这些条目单独选作目标。若目标目录本身是挂载点或其内部含已挂载目录，则跳过整个目标，不自动卸载。执行前独立核对当时的挂载关系，不依赖是否完整扫描；无法确认时跳过并说明原因。
- **Q15 使用中的内容**：仍允许尝试移除被其他应用打开的文件或目录，由系统移除结果决定成功与否；系统拒绝只报告失败，不自动关闭相关应用。磁盘条目移除不增加全机打开文件检查，不继承会话记录移除的「使用中即跳过」规则。
- **Q16 确认与执行生命周期**：打开确认框时冻结这次操作的目标与顺序；单项入口只确认该项，批量入口只确认勾选集合，当前目录入口只确认当前目录，不合并其他勾选。取消确认不执行，重新发起重新冻结。执行期间锁定本页的勾选、目录导航、重扫和再次移除；允许切换到其他页面，批次继续，返回可查看进度与结果。退出应用不构成撤销，重启不自动继续未完成的移除；历史沿用既有中断记录规则，不推断未记录目标的执行结果。
- **Q17 重扫与重试**：无论成功、部分失败或用户停止后续项，批次结束清空勾选并自动重扫；旧扫描记录失去后续移除资格。未取得可用新结果时，保留的旧记录只能查看，用户可以手动重新扫描，不自动重试移除；新一轮扫描开始后仍可停止，其部分结果继续遵循 Q4、Q8 的资格规则。新扫描不继承旧条目 ID 或勾选，失败项需要从新结果重新选择并确认。

最终范围为 Q1–Q17：在现有磁盘扫描结果上提供受本轮对象身份与路径边界约束的系统废纸篓移除，覆盖列表和树图、单项和当前层批量、确认与逐项结果、停止、自动重扫及现有维护历史。恢复由系统废纸篓负责。

## 实现衔接

- 移除对象引用当前后端扫描会话及条目身份；由后端冻结并复核目标，不能接受前端任意路径作为移除授权，也不能把扫描开始时的路径规范化当作执行时护栏。
- 单个批次的逐项执行、停止与真实结果记录遵循现有维护操作外壳和项目清理批次范式。切页不会改变确认范围，历史写入失败也不改变执行结果；确认与原生系统调用结果分开处理。
- 自动重扫属于后续读取，按原扫描起点发起，不使用尚未提交的路径输入草稿。原生新扫描会生成新节点身份，恢复浏览位置需按仍存在的目录路径重新定位。
- 列表与树图共享移除工作流；扫描期间与执行期间的禁用规则须在后端也成立。旧请求、旧确认或旧扫描的迟到结果不能作用于新一轮。
- 系统移除异常不能证明目标原封不动；保留原始错误，后续读取与执行结果分开陈述，不自动对同一路径重试或退化为永久删除。

## 已确认行为对应的验收场景

- 完成扫描后，普通文件和整个目录可单项或批量移入系统废纸篓；扫描运行期间不能开始移除。主动停止、部分读取与达到条目上限后，已识别的普通文件和目录按同样规则判断资格。
- 扫描起点、当前用户主目录及其祖先、符号链接、挂载点、特殊与未知条目不能直接成为移除目标；没有权限或系统拒绝只产生失败，不申请提权或永久删除。
- 在超过 200 个直接子项的目录中加载更多：已有勾选保留，「全选已显示」只选当前分组中已显示的合格条目，后续加载条目不自动勾选。换目录、换分组或重扫清空选择，同目录切换列表和树图保留选择。
- 列表单项操作、树图文件详情和方块右键菜单均进入同一移除确认；目录点击仍进入下一层，路径栏菜单可移除非起点的当前目录。「其他 N 项」只打开分组列表，不能作为单个目录移除。
- 单项和批量确认均展示实际目标完整路径与数量；取消没有移除效果。选中未读完整的目录时显示影响整个目录、包含未扫描内容及占用不完整的说明。
- 已勾选多个条目后使用某行单项操作，确认范围只有该项；当前目录入口也只确认该目录，不把已有勾选混入。确认取消后旧确认不能执行，重新发起时重新冻结目标与顺序。
- 扫描后把目标移走、用同名新对象替换或把中间路径替换为链接：执行时跳过并说明原因。仍为同一个文件时修改内容、仍为同一个目录时新增文件，明确选择依然作用于整个当前对象；不按扫描清单逐个移除后代。
- 选定目录包含指向范围外的符号链接或特殊条目：整体移动目录时保留链接本身与特殊条目，范围外链接目标不被移动。链接和特殊条目不能通过单项或批量入口直接成为目标。
- 目标本身为挂载点或内部含挂载目录时跳过整个目标，不卸载磁盘；覆盖同设备挂载、扫描时尚未发现的挂载点和扫描结束后新增挂载。无法确认挂载关系时跳过并解释原因，不能把扫描完整度当作无挂载证明。
- 目标或其内部文件被其他应用打开时，仍可进入移除尝试；应用不主动关闭相关程序，也不以全机打开文件检查作为前置条件。系统接受与拒绝分别呈现实际结果，不套用会话记录的使用中保护规则。
- 注入单项失败时其余目标继续；用户停止时当前项完成后结束后续派发，分别展示已移入、跳过、失败和未执行项，结果不暗示整批回滚。
- 批次执行期间不能更改本页勾选、目录导航或启动新扫描、第二次移除；切换应用页面不停止批次，返回后显示同一批次进度或结果。旧批次的停止请求不能影响新批次。
- 在执行途中退出并重启应用：不自动继续移除，不将已完成项目还原，未关闭的历史按现有规则显示中断；没有记录的目标不能被推断为成功或失败。
- 移除完成后保留逐项结果，自动从原起点重新扫描并更新图表；若当前目录被移除则返回仍存在的祖先目录。硬链接场景通过重新测量得到父目录占用，不能简单减去目标大小。
- 批次成功、部分失败或用户停止后续项都清空选择并触发自动重扫，路径输入草稿不改变重扫起点。重扫开始失败时旧记录只读；新一轮扫描开始后若主动停止，部分结果仍按 Q4、Q8 判断资格，不继承旧勾选或旧条目身份。
- 重扫失败、停止或只得到部分结果时，原逐项执行结果仍可查看；失败项目不自动再次移除，需从新扫描结果重新选择并确认。系统报错后路径变化也不能触发对该路径的自动重试。
- 维护历史记录一次确认及逐项执行事实；后续读取失败与移除结果分别呈现。历史记录不提供撤销或再次移除授权，恢复由系统废纸篓负责。
