# 磁盘条目移除实现验证

日期：2026-11-20。范围：[PRD Q1–Q17](PRD.md)、[ADR-0038](../../docs/adr/0038-disk-entry-removal-selects-whole-objects.md)。

## 已完成

- 列表行单项移除、当前目录同层批量选择、全选已显示、树图右键、文件详情以及当前目录菜单，共用确认与执行工作流。
- 扫描完成或停止后才能移除；确认冻结目标及顺序，原生端根据扫描 ID 与条目 ID 取得路径，不接受客户端任意路径作为移除授权。
- 扫描起点、主目录及其祖先、链接、挂载点、特殊和未知条目不能直接移除。目标和祖先身份变化时跳过；目录内挂载检查使用执行当时的系统挂载表。
- 主目录保护和挂载边界同时比较对象身份，避免 `/Users/...` 与 `/System/Volumes/Data/Users/...` 等路径别名绕过边界。
- 复用 Finder 系统废纸篓操作。目录作为整体移动，包含未扫描和后来新增的内容；没有永久删除后备路径。
- 顺序执行，逐项记录成功、跳过或失败；停止不取消已派发的系统调用。切换应用页面后批次继续。
- 批次结束清空选择并使旧扫描失去移除资格，从原起点自动重扫，按路径恢复仍存在的浏览目录。重扫失败保留旧结果只读，不自动重试移除。
- 接入维护历史，保留确认范围与逐项结果。中断时没有记录的目标显示“结果未确认”；明确停止后的剩余项显示“未执行（批次停止）”。历史可返回磁盘扫描页。

## 验证边界

- Finder 按路径执行，身份与挂载复核到系统调用之间无法原子锁住外部进程的重命名或挂载变化；复核不是全文件系统并发事务。
- 实际外接卷、同设备新挂载、特殊文件种类及应用强制退出没有逐一做原生端到端操作；相关跳过规则用注入场景验证，中断记录沿用现有维护历史机制。
- 浏览器交互和原生文件操作分别验证，未进行完整桌面 WebView 到 IPC 再到 Finder 的端到端自动化。
- 构建仍报告既有主包超过 500 kB 的提示；树图保持独立懒加载块。本次没有调整打包策略。
