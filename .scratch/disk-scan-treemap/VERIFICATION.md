# 磁盘扫描矩形树图验收

日期：2026-11-20。对应 [PRD.md](./PRD.md) 的 Q1–Q12。

## 已实现

- 列表 / 矩形树图共用扫描和当前目录，本次应用运行期间保留展示模式；首次默认列表。
- Rust 从当前目录全部直接子项中选出最大的 200 个正占用条目，汇总其余正占用为「其他 N 项」，单次响应包含路径、大小、状态及无面积条目计数。
- 面积比较兄弟条目的相对权重；遵守 ADR-0037，聚合从子项相加，不从父目录相减。未知、真实零和排除项不占虚构面积。
- 单击目录下钻，路径导航返回；文件单击显示详情并支持复制路径。文件名和路径通过 DOM textContent 写入提示，避免作为 HTML 执行。
- 「其他」及状态计数进入临时分组列表，支持分页、查看全部，导航或返回图表清除分组。分组在原生完整层级筛选后分页，随扫描更新。
- 每秒至多更新一次图表。鼠标悬停、触摸操作或键盘焦点期间保留整批数据，有新记录时提示；恢复时跳过旧缓存，直接读取最新批次。主动导航与重扫清除旧暂停并拒绝过时响应。
- ECharts 按需注册并懒加载，Canvas 随窗口和主题变化更新，离开时释放实例。颜色按条目身份稳定分配，关闭平移、滚轮缩放和布局动画。
