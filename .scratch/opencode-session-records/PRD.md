# OpenCode 会话记录

Status: ready-for-agent

## 已确认的方向

- 在现有「会话记录」页面增加 OpenCode 来源，不扩展到 OpenCode 配置或插件管理。
- 仅连接 OpenCode 已登记且正在运行的本地服务；未发现服务时显示暂不可读取并提供重试，不启动服务、不提供地址配置。
- 认证信息不显示或写入持久配置；打开会话时仅短暂写入权限受限、启动后自删的脚本，通过环境变量交给 CLI。会话列表与元数据 API 只读；删除通过已登记服务的官方 API 执行。
- 全局分页读取所有项目、归档会话及子会话，按 `time.updated` 倒序。
- 只展示标题、最后活动时间、工作目录、归档状态与父子关系；不读取会话消息、不展示记录大小。
- 搜索标题和工作目录，以归档状态筛选；进入页面时读取，支持手动刷新，不后台轮询。
- 每条记录提供单条永久删除；列表另支持勾选、全选当前结果、取消选择和批量永久删除。确认前展示所选会话及其全部已读取级联后代，并按父子关系去重实际删除请求。通过已登记服务的 `DELETE /api/session/{id}` 执行，服务端会连同该会话的子会话一起删除。批量删除时后端重新读取全局会话元数据，计算最新级联范围并逐项复核会话仍存在、未运行；若任一项仍在运行、已不存在或活动状态接口不可用，则整批不开始删除。预检通过后按序删除；执行期间首项失败时停止后续操作并逐项报告，已成功项无法回滚。确认界面明确说明永久删除不可恢复，并提醒用户先结束运行中的会话。不直接修改 SQLite，不移入废纸篓。
- 每条记录提供「在 OpenCode 中打开」操作。打开前通过当前已登记服务复核会话存在并取得该会话工作目录，再用 `opencode attach <url> --dir <directory> --session <id>` 连接；不启动后台服务、不传 `--fork`。归档与子会话均可打开。失败时给出可重试错误。
- 打开通过 macOS Terminal 执行交互 CLI；CLI 不存在或服务已停止时明确报错。凭据不得进入 CLI 参数、终端命令历史、持久配置或应用日志。

术语见 [CONTEXT.md](../../CONTEXT.md)。服务发现与读取边界见 [ADR-0021](../../docs/adr/0021-opencode-session-records-use-registered-read-only-service.md)。

## 验收场景

| 场景 | 预期行为 |
| --- | --- |
| 服务未登记或已停止 | 显示暂不可读取，允许手动重试，不启动服务 |
| 服务登记损坏、不兼容或认证失败 | 显示安全的来源错误，不显示服务密码或认证 URL |
| 全局会话超过一页 | 继续使用服务端游标读取，直到没有下一页 |
| 同时有父会话、子会话、归档会话 | 均展示，父子关系可辨认，归档可筛选 |
| 标题或工作目录匹配搜索词 | 记录出现在搜索结果中 |
| 打开时服务已停止或会话已不存在 | 不启动新服务、不创建会话，提示刷新或重试 |
| 打开归档会话或子会话 | 连接指定会话，不传 `--fork`，不解除归档 |
| 取消永久删除确认 | 不调用删除接口，会话保留 |
| 确认删除有子会话的记录 | 通过 OpenCode 服务删除该会话及其全部子会话；提示这是不可恢复的永久删除，完成后刷新列表 |
| 删除仍在运行的会话 | 后端识别活动会话并拒绝删除，提示先在 OpenCode 中结束会话 |
| 批量删除时任一目标预检失败 | 整批不发送任何删除请求，说明失败目标并保留会话 |
| 批量删除时同时选择父会话和子会话 | 确认预览展开所有已读取后代，实际请求只删除所选父会话一次 |
| 批量删除执行中遇到冲突或失败 | 停止后续删除，逐项报告成功、失败和未执行项；提醒刷新核对 |
| 删除前会话已不存在 | 不发送删除请求，提示刷新列表 |
| 删除期间会话变为运行中，服务端返回冲突 | 显示运行中错误，不报告删除成功，也不自动重试 |
| 删除时服务失败或响应不确定 | 显示错误并允许刷新核对，不自动重复删除请求 |
| OpenCode 服务返回消息接口或正文数据 | 本工具不请求、不保存、不展示该数据 |
| Codex／Claude 的移除操作 | 不受 OpenCode 删除影响，既有来源操作保持不变 |
