# OpenCode 会话时间视图与按年龄永久删除

Status: done

## 已确认的方向

- 在现有 OpenCode 会话记录页增加与 Codex／Claude 一致的时间视图和按年龄操作，不扩展到配置或插件管理。
- 暂不增加「按大小」：当前已登记的 OpenCode 2.1.1 服务元数据没有单条字节大小；继续遵守不读取会话消息、不展示记录大小的约定，不用 token 用量冒充大小。
- 提供「按最后活动时间」视图，按本机本地日历的年月分组，最近的月份和记录在前，月份可折叠。
- 保留手动刷新，不新增重复的刷新入口。
- 提供「永久删除 7 天前的记录」与「永久删除 30 天前的记录」，作用于整个 OpenCode 来源，不受搜索或归档筛选限制，并明确提示该范围。
- 按年龄选定的目标及其全部后代必须都早于门槛且未运行；有近期或运行中后代的父会话保留。
- 使用已登记服务的官方永久删除接口，明确说明级联删除、无法恢复、不进入废纸篓；不直接读取或修改 SQLite。
- 用户明确选择的单条／批量永久删除保留现有语义，不套用年龄门槛。
- 确认时刻减去 7／30 个 24 小时为固定门槛，最后活动时间严格早于门槛才符合条件；冻结确认名单，不加入随后跨过门槛的新记录。
- 确认后任一目标或后代不再符合年龄、存在或未运行条件，整批不开始，提示刷新后重新确认。
- 确认后后代集合或父子关系变化，整批不开始，不扩大已确认范围。
- 父会话被保留时，符合条件的独立旧子分支仍可删除，不影响其父会话。
- 每次实际删除前再次复核剩余目标；执行开始后发现变化或删除失败，停止后续操作，保留并报告已完成的结果，不回滚或自动重试。
- 列表读取补充活动状态，按年龄按钮排除运行中的分支；活动状态不可读时仍展示元数据，禁用按年龄操作并提供刷新恢复。
- 按年龄确认展示冻结门槛、全部待删除记录及父子关系；无候选、读取中、执行中或服务不可用时禁用入口。

## 验收场景

- 时间视图按本机年月分组，可折叠；搜索和归档筛选后仍按活动时间倒序。
- 按年龄操作不受搜索和归档筛选限制，严格排除门槛时刻、近期记录及运行中分支。
- 旧父会话包含近期／运行中后代时保留父会话；符合条件的独立旧子分支仍能成为目标。
- 取消确认或重复确认不额外发送请求；确认后新增符合条件的记录不自动加入。
- 首次预检发现年龄、活动状态、存在或级联范围变化时，零 DELETE 请求；执行中发现变化则停止，报告成功、失败和未执行项。
- 操作结果先保存，再刷新列表；刷新失败可单独重试读取，不能重复删除。
- 测试使用内存夹具和本地模拟 HTTP 服务，不删除真实 OpenCode 会话。

## 已核实的约束

- 列表读取会话元数据及已登记服务的活动状态；活动状态不可读时不抹掉元数据。确认摘要冻结已选目标及当时已读取的后代。
- 按年龄删除请求包含冻结门槛、删除根与已确认记录的父子关系；后端重读全局元数据及活动状态，核对完整范围后才删除，不直接使用前端年龄判断作为资格。
- 当前服务 OpenAPI 未提供按年龄的条件删除、版本条件或检查与删除原子性的保证；不得将客户端复核表述为服务端原子保证。
