- `pnpm test`：42 个文件、323 项测试通过。
- `cargo test --lib`（`src-tauri/`）：293 项通过，10 项既有环境相关测试忽略。
- 窄屏布局及区域语义调整后，4 个会话模块测试文件的 41 项测试再次通过；TypeScript 检查和 Vite 生产构建通过。
- Vite 仍有既有主包超过 500 kB 的提示。
- `git diff --check`：通过。

## 行为证据

- 前端策略测试验证本机年月分组、严格 7／30 个 24 小时门槛、近期与运行中后代保护、保留父会话时旧子分支独立选定，以及活动状态不可读时不形成年龄确认。
- hook 测试验证冻结门槛和完整后代关系、取消与重复确认、首次预检拒绝后的刷新，以及仅重试读取。
- 页面交互测试使用真实 hook 和模拟 Tauri 命令，验证月份折叠、搜索结果为空时仍预览整个来源的年龄目标、活动状态未知时保留元数据并禁用年龄入口。
- Rust 测试使用本地模拟 HTTP 服务，验证缺失目标、父子关系变化、新增后代、活动时间更新、运行中后代和活动接口失败均不发送 DELETE；执行开始后范围变化或删除失败停止后续操作，报告部分结果。
- 使用 agent-browser 对 [合成数据页面](browser-review.html) 检查 1280×900 和 390×844。窄屏行内操作独占一行，长路径不产生横向溢出，确认框在屏幕内显示；模拟确认只删除 `ses_old` 及其旧后代，近期记录、具有近期后代的旧父会话、运行中记录均保留，且只发送一次年龄操作和一次后续读取。
- 浏览器没有运行错误。axe WCAG A／AA 检查无确定违规，列出记录区域标签与既有页签数字对比度两项人工复核；记录区域已补充 `region` 语义，页签对比度不属于本次变更。

## 验证边界

本轮不请求会话正文，不对真实用户会话执行删除。官方 API 没有条件删除或原子性契约；测试验证客户端复核及停止行为，不能证明最后一次检查与 DELETE 之间没有竞态。
