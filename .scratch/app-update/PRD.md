# 应用更新

Status: done

## 目标与范围

为「包管理器控制中心」增加应用自身的更新能力：启动后检查新版本、在设置页展示与安装更新、安装完成后自动重启，并配套 GitHub Releases 发布流水线。

范围为应用安装包的检查、下载、签名验证、安装与重启，以及发布该安装包所需的最小流水线。不包含 Apple Developer ID 签名与公证，不包含对包管理器、插件、技能或项目数据的升级。领域词汇见 [CONTEXT.md](../../CONTEXT.md) 的「应用更新」；渠道与技术选择见 [ADR-0034](../../docs/adr/0034-app-update-via-github-releases.md)。

## 行为

- 启动后延迟 1 秒自动检查一次；设置页可手动检查；不轮询。
- 开发模式不检查更新，设置页说明原因并禁用检查。
- 后台检查失败不弹全局提示；错误只在设置页展示。
- 发现新版本时弹出 sonner 常驻提示；关闭只隐藏本次会话，「跳过此版本」才持久化。
- 设置页展示当前版本、可用版本、下载进度（总长未知时不确定态）、发布说明与错误。
- 安装完成后自动重启；重启失败时提示用户手动重新打开。
- 错误文案区分网络失败、未找到更新服务器、签名验证失败与其他失败。

## 发布链路

- `v*` 标签触发 GitHub Actions，只构建 `aarch64-apple-darwin` 的 dmg 与 app。
- `tauri-action` 生成并上传 `latest.json` 与签名；上传后校验版本、下载地址与签名非空。
- 更新签名密钥由 `pnpm tauri signer generate` 生成；私钥与密码放 GitHub Secrets，公钥入库。
- `CHANGELOG.md` 由 git-cliff 生成，作为 Release body 与更新说明。
