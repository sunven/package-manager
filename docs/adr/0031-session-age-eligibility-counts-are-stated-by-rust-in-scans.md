# 会话年龄可操作计数由 Rust 在扫描时陈述

Codex/Claude 的按年龄移除计数与 OpenCode 的按年龄删除计数此前由前端从扫描记录重新计算；OpenCode 的父级级联资格因此存在两份实现，与 Rust 的 `eligible_ids` 可能漂移。决定在两份会话扫描结果中各带 `ageEligible: { days7, days30 }`，由 Rust 用扫描时的同一份记录、使用中/运行中状态和最后活动时间算出。计数是观察事实，不是清理授权；执行时仍按 ADR-0007 与 ADR-0022 重新核验。

## Considered Options

- 打开确认框时调用新的预览命令：计数更新，但增加一轮 IPC、加载态和第二条错误路径，收益只是晚几秒的观察。否决。
- 继续由前端从扫描记录计算：两套规则需要同步修改，OpenCode 的级联尤其容易漂移。否决。
- 扫描结果携带计数：采纳；页面直接读取，前端删除镜像规则。

## Consequences

- 扫描不完整时计数只是下限；现有确认文案继续说明执行前会重新检查。
- 会话的计数排除使用中记录，与「当前可移入废纸篓」的展示口径一致；执行候选仍包含并在执行时跳过使用中记录。
- OpenCode 的计数使用与删除计划相同的级联规则，统计符合条件的记录数（不是删除根数）。
- 前端不再保留 `recordsOlderThan` / `openCodeAgeEligibleCount` 的镜像规则。
- 共享会话操作 hook 同时收窄：后续读取记录改为注入的共享 helper，adapter 的 `removeCompleted` 仅保留一份按记录过滤的实现；VSCode 扫描继续使用自己的 `workspaces` 集合。
- ADR-0021、ADR-0022、ADR-0023 继续有效。
