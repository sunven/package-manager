# Maven 未引用构件按指定范围检查并移入废纸篓

用户于 2026-11-04 要求提供未使用依赖清理，并选择以指定 Maven 项目的扫描范围为判断依据。决定增加独立的 Maven 引用检查：只读解析所选目录的 POM、模块、本地父 POM、所有 profile、父构件、依赖管理、传递依赖、插件、报告和扩展，构成保守的 GA 保护闭包；一个 GA 被引用就保护全部版本。默认要求完整传递引用：缺失 POM 时不生成清理授权。另提供用户主动选择的“仅检查本地已有 POM”方式，只对已读取模型进行引用保护；不存在任何本地版本的已知 GA 列入缺失模型提示，允许按该有限范围确认候选。无法解析坐标、已有构件的模型无法读取、非标准仓库布局或达到上限时，两种方式都不生成清理授权。只允许当前后端扫描会话签发的、来源明确为远程且未被保护的版本目录移入废纸篓。

该决定部分替代 [ADR-0001](./0001-delegated-cache-cleanup.md) 对 Maven 本地仓库维护的禁止。官方 purge 的作用范围与本功能不同，通用清理表继续没有 Maven 方案；本功能不从前端接受仓库或删除路径。执行前重新确认同一仓库来源、重新计算保护闭包，并核对项目模型、候选文件与路径身份、打开文件；失败或变化不会退化为永久删除。执行后的扫描授权被消费，后续维护需要重扫。

## Considered Options

- 根据多版本、SNAPSHOT 或文件时间判断未使用：不采用；它们不能证明项目没有引用。
- 精确按版本求 Maven 有效模型：首版不采用；继承、版本范围、所有 profile 组合与插件动态行为难以由只读 XML 完整复现，保留被引用 GA 的全部版本更保守。
- 执行 dependency:analyze / go-offline 作为只读扫描：不采用；它们会启动 Maven、加载扩展或执行编译/解析插件，而且输出不能提供全机引用关系。
- 删除 artifactId 目录或整个仓库：不采用；本地安装构件可能没有远程副本，且候选必须逐个版本确认。

## Consequences

- 本地已有 POM 方式是对完整检查规则的显式范围例外。它不能证明缺失模型的传递依赖未引用候选，不自动下载模型，也不默认启用。切换方式清除结果与选择并要求重扫；结果可查看全部缺失 GA，确认框提示缺失数量与传递引用边界。后端冻结检查方式与缺失模型集合，执行时以同一方式重算；缺失集合变化要求重扫。维护历史记录该方式与缺失数量。
- 模型读取集中处理父属性继承和本地父 GAV 匹配，支持父路径指向目录与 CI 的 `${revision}` 继承。所有 profile 的有限属性值均纳入保护，继承的声明也按子模型属性重新展开；无法确定的属性不猜测。按 Maven 模型容器识别引用，插件 configuration 中同名节点属于动态配置边界。兼容 Maven 默认 Latin-1 命名实体；不读取外部 DTD。
- 外部 POM 缺失时，可读取对应 JAR 中该 GA 的 `META-INF/maven/.../pom.xml`；不执行 JAR，不把内容解压到用户目录。JAR 最多 64 MiB、内嵌 XML 最多 4 MiB，POM 读取仍计入模型预算。记录缺失的外部 POM 与 JAR 内容摘要及身份，每个目标执行前重新检查；保留插件的模型变化使后续目标跳过。
- 未引用仅表示指定范围的 POM 中未发现引用。范围外项目、插件按代码/配置动态取得的构件仍可能需要候选；产品在结果与确认中说明边界，不承诺完整运行时使用分析。
- 保留全部 Maven 插件版本、已知隐式插件/provider 构件族、本地安装或来源不明构件，并保护其声明的依赖闭包。每个 payload 都要有非空远程来源记录；混合来源或缺失记录不构成下载证明。
- 远程来源不保证今天仍可重新下载。移入废纸篓提供恢复机会，清空之前不承诺释放空间。
- 应用操作锁与打开文件检查不能代替 Maven Resolver 的跨进程锁，不能保证与终端或 IDE 中同时开始的构建无竞争。
- 仓库路径规范化后仍须排除用户目录及其上级目录，并读取用户和全局 settings；解析或读取失败不会退回默认路径执行维护。每个目标执行前复核模型、来源记录与发现目录；中途新增项目/构件、内容或来源变化会让后续目标跳过。已经移走的目录只从预期清单中扣除，重新出现不会自动信任。打开文件检查限时执行，诊断输出视为无法确认。
- 保留目录预设，引用检查不继承项目派生数据扫描的清理授权；本功能结果与确认独立，不把候选写入历史快照。
- 自动发现排除 `.git`、`target`、`node_modules`、Flutter SDK/生成依赖目录（`.fvm`、`.dart_tool`、`.symlinks`）及代理工具元数据目录（`.agents`、`.claude`、`.codex`、`.grok`、`.opencode`、`.workbuddy`、`.superpowers`）。这些目录里的依赖/技能链接和示例 POM 不属于自动发现范围；用户选择它们作为根目录或 POM 显式声明其下模块时，仍读取对应模型。范围内项目/POM 和仓库的符号链接仍按原规则处理。
- 模型预算按实际 POM 读取计数，一轮最多 10000 个；来源记录、缺失相对父路径和扩展定义的文件观察不额外消耗 POM 数量预算。30 秒总耗时预算独立检查，诊断包含进度、上限和触发的具体预算；数量误计数的修正不绕过引用不完整的保护。
- 按 ADR-0027 / ADR-0030 复用维护操作外壳，在管理器维护历史中记录确认的范围与构件、逐目标结果；维护记录只读，不提供撤销授权。
