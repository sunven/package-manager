# OpenCode 按年龄永久删除保留有近期后代的会话

OpenCode 官方删除接口会连带删除目标的全部子会话，因此仅按父会话的最后活动时间选定目标，可能永久删除近期仍有活动的后代。按 7／30 天永久删除时，只有目标及其全部后代都早于门槛且未运行，目标才符合条件；有近期或运行中后代的父会话保留，不以父会话的年龄授权删除整个分支。此规则用于按年龄选定目标，不改变用户明确选择的单条和批量永久删除。

确认冻结门槛、目标与级联范围，不自动加入新目标。执行前重新核对年龄、活动状态和父子关系；任一变化使整批不开始，要求刷新后重新确认。执行开始后每次删除前再次复核剩余范围，发现变化或失败即停止后续操作，已成功项不能回滚。官方 API 没有条件删除或检查与删除的原子性保证，客户端复核仍存在最后一次检查与 DELETE 之间的竞态窗口。
