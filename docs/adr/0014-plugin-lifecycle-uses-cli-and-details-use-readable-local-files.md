# 插件生命周期委托 CLI，详情补读可访问的本地包

市场与插件管理补全继续采用官方 CLI 作为安装事实及安装、重新安装、卸载的执行入口；详情可以补读本地可访问的插件声明，但不据此推断安装状态。官方暂不建议生产客户端使用 `plugin/read` 等实验接口，而稳定 CLI 未承诺完整元数据，因此选择接受远程未下载插件的详情不完整，不为预览自动安装或建立另一套源码下载机制。

这延续 ADR-0011 的安装事实边界，并扩展 ADR-0012 当时排除的独立插件生命周期范围；市场同步可能连带影响多个插件的结论不变。重复 `plugin add` 在 0.162.1 本地 fixture 中会刷新文件并将禁用插件启用，因此界面使用「重新安装」并明确启用后果，不承诺保留禁用状态或取得上游最新版。

方案来自[本轮 PRD](../../.scratch/codex-marketplace-plugin-completion/PRD.md)的三轮确认，用户已确认整体共同理解。官方约束、已核实结果及单版本实验限制见[事实核查](../../.scratch/codex-marketplace-plugin-completion/RESEARCH.md)。
