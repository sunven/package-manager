# Grok Build 会话记录整体移入废纸篓并保留外部索引

Grok Build 每条本机会话记录由一个目录中的日志、摘要及附属数据组成，目录外另有搜索索引；原生永久删除命令的远端影响与运行中保护尚无可靠边界。决定将单条本机会话目录整体移入废纸篓，保留目录外搜索索引与远端副本，以获得可恢复、仅限本机的移除语义。移除要求 Grok Build 已退出，检测到运行或无法可靠检查时阻止操作；来源仍可读取。

实现采用独立的 Grok 目录记录策略。按年龄移除使用 `last_active_at`；缺失或无效的记录不参与按年龄移除，仍可在满足其他条件时被明确选择。

## Considered Options

- 调用 `grok sessions delete`：原生操作是永久删除，无法满足废纸篓恢复语义，也没有核实其远端影响与运行中保护，因此不采用。
- 只移走一个日志文件：会把摘要、其他恢复数据和附属文件留在原处，不符合一条完整记录的边界，因此不采用。
- 移走目录并直接修改共享搜索索引：会让本工具持有 Grok 的索引写入与兼容责任，也使文件移除、索引修改和废纸篓恢复成为多步操作，因此不采用。
- 只凭锁文件或运行登记判断可移除：锁文件可以长期存在，运行登记也可能遗漏 headless 会话，不能据此证明 Grok 已退出，因此不采用。

## Consequences

- 移除后的记录仍可能在 Grok 搜索中留下摘要或片段；本操作不承诺彻底抹除，也不修改远端副本。
- 父子／派生记录只按各自选择与资格处理，不级联移除，不改写保留记录中的引用。确认时说明关联记录会保留且原引用可能失效；独立存储不等于保证其全部恢复能力不依赖被移除记录。
- 占用表示会话目录内文件的大小；记录离开原目录不等于已经释放物理空间。
- 为 [ADR-0009](0009-symlinks-are-not-session-records.md) 的「普通文件」限制增加 Grok 来源的普通会话目录例外，继续遵守不跟随符号链接的边界。Codex／Claude 的文件资格不变。
- 「Grok Build 仍在运行」是来源级操作资格原因，不把所有记录误标为「使用中」，不改变该词已有含义。
- 运行状态检测需要覆盖支持范围内的会话宿主；证据不足时保留记录。前置检查不构成与 Grok 启动之间的原子互斥保证。
- 批量执行在每项之前复核运行状态；发现 Grok 启动或状态无法确认时停止剩余项，已成功项不回滚。普通单条移除失败则继续其余记录，分别报告成功、跳过、失败与未执行。
- 沿用 [ADR-0023](0023-session-record-operations-share-lifecycle-not-policy.md) 的共享操作生命周期，Grok 的目录资格、运行保护和移除范围由独立来源策略拥有。
