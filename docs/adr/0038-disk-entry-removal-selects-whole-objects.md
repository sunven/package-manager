# 磁盘条目移除选择整个对象，执行时复核身份

磁盘扫描呈现任意文件与目录的历史观察，不能证明内容可重建或仍与扫描时一致；用户于 2026-11-20 确认增加显式选定目标并移入系统废纸篓的维护操作。决定选择作用于同一个普通文件或整个目录，目录未完整读取、后来新增内容或对象内容变化本身不取消选择；执行前仍须复核目标与所在路径的身份，消失、同名替换或路径变成符号链接时跳过。这个边界允许从部分扫描结果整理整个目录，代价是确认范围包含未逐个展示的后代，因此必须在确认中说明；不采用只移走扫描时已枚举后代的方式，也不把其他领域对可重建性、引用或活动时间的资格规则套用到磁盘条目。

整个目录可以包含链接与特殊条目，但不跟随链接移动目标；直接选定链接、挂载点或特殊条目的操作仍不提供。若目标本身是挂载点或内部含挂载目录，则跳过整个目标，不自动卸载；挂载关系须在执行前独立核实，不能由扫描完整度推断。使用中的内容仍允许尝试移入废纸篓，由系统返回执行结果，不继承会话记录的使用中检查或关闭相关应用。

每批结束后旧扫描失去移除资格，清空选择并从原起点重新扫描；用户需从新结果选择后续目标，重扫失败不改变已记录的移除结果。新扫描的部分结果仍可按上述规则选择，既保留部分扫描的使用场景，也避免让旧观察和失败重试继续作用于同一路径上后来出现的对象。需求和验收场景见[磁盘条目移除 PRD](../../.scratch/disk-entry-removal/PRD.md)。
