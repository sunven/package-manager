# 会话记录移除进入废纸篓

会话记录不能重建，移除它的动机却是让它离开代理 CLI 的原目录。单条移除和按年龄批量移除都把文件移入废纸篓，而不是永久删除。离开原目录的体积可以马上从列表里消失，物理空间要等废纸篓清空才释放。

## Considered Options

永久删除能立刻释放磁盘，也和 `codex-config` 的会话删除以及本工具的依赖目录清理一致。否决是因为会话记录没有重建途径，误移除的代价和删掉可以重装的 `node_modules` 不同。

## Consequences

- 页面上的占用表示会话记录离开原目录的体积，不表示已经释放的物理空间。
- 不要为了让磁盘数字立刻下降，把会话记录移除改成永久删除。
