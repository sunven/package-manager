# 明确选中的会话记录按单条资格移除

会话记录页可以勾选一个来源里的多条记录，确认一次后移入废纸篓。这次移除的资格和单条移除相同：动手时仍是会话记录，且未在使用中。不套用 7 天或 30 天的最后活动时间门槛，因此没有最后活动时间、或活动时间很近的记录，只要被明确选中，就可以进入这一次移除。

## Considered Options

选中之后仍按年龄再滤一遍。这样和现有的「移除 N 天前」共用一条规则。否决是因为多选就是为了移走年龄批量不会带走的具体记录；再滤一遍会把用户刚刚勾上的记录悄悄留下。

按确认时的名单原样移完，不再看文件是否仍被打开。否决原因与按年龄移除相同：确认之后文件可能被代理进程打开。

## Consequences

- 一次确认只作用于当前来源。
- 使用中的记录不能被勾选；动手时变为使用中的记录留下，并且不计入失败。
- 确认条数可以大于实际移入废纸篓的条数。
- 单个文件移入废纸篓失败不阻止其余仍符合资格的记录。
