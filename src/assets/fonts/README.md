# Chillax

Locally bundled Medium (500) and Semibold (600) WOFF2 files for the Hum theme, served without a runtime network dependency.

Source: [Fontshare Chillax](https://www.fontshare.com/fonts/chillax), Indian Type Foundry. The files were retrieved from the Fontshare CSS endpoint on 2026-11-03:

`https://api.fontshare.com/v2/css?f[]=chillax@500,600&display=swap`

See the source's font license for redistribution terms. Chinese text uses the system sans fallbacks declared in `src/tokens.css`.
